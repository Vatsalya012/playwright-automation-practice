## How to Run

1. Clone this repository.
2. Install the dependencies:

   ```bash
   npm install
   ```

3. Install the required Playwright browsers:

   ```bash
   npx playwright install
   ```

4. Run all tests:

   ```bash
   npx playwright test
   ```

5. Run tests in headed mode:

   ```bash
   npx playwright test --headed
   ```
